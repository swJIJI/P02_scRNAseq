### 6. Sample-level Seurat object 생성

각 sample에서 `CreateSeuratObject()`를 실행했다.

QC threshold를 아직 결정하지 않았으므로:

```
min.cells = 0
min.features = 0
```

으로 설정했다.

Cell barcode 충돌 방지를 위해:

```
RenameCells(
  obj,
  add.cell.id = sample_id
)
```

를 사용했다.

추가한 sample-level metadata:

```
sample_id
pdo_source
timepoint
biological_replicate
culture_batch
```

각 sample의 Seurat object에서 feature 수와 cell 수가 `Read10X()` 결과와 동일함을 확인했다.
